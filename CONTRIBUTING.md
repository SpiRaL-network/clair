# Contribuer

Utiliser Windows 64 bits et Python 3.12. Installer les dépendances avec
`python -m pip install -r requirements.lock.txt`, puis lancer
`python -m pytest tests -q`. Les tests n'exigent pas les modèles, les moteurs
llama.cpp ni des périphériques audio.

Pour exécuter l'application, suivre le README. Documenter les changements de
comportement et les validations réelles lorsqu'ils affectent l'audio ou l'inférence.
Ne pas committer d'enregistrements, transcriptions, journaux, préférences locales,
clés, modèles ou binaires téléchargés.

Les contributions originales doivent pouvoir être distribuées sous la licence
MIT du projet. Conserver les attributions lorsqu'un composant tiers est ajouté.
